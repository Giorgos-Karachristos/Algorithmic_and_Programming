# Algorithmic & Programming
This repository contains the solutions to the exercises from the lab Algorithmic & Programming

Rules:
1. Follow the description of each exercise.
2. Always print outputs in English.

## Lab 1  
### Exercise 1: 		
Create a Java program in Notepad, format the code, and execute it in MS-DOS environment

## Lab 7 One-dimensional array
### Exercise 1:
Creates an array of 10 random integers, displays its elements, finds and prints the positions of the maximum and minimum values, counts how many elements are above the average, and swaps two adjacent random elements before displaying the updated array
## Lab 8 Two-dimensional array
### Exercise 1:
